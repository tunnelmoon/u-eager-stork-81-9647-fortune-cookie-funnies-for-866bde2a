# Fortune Cookie Funnies for Engineers

make.fun bounty entry: one fortune cookie message for a software engineer,
at most 120 characters, written as a single line.

Entry: "You will find the bug in the line you swore you already checked. Twice."

`main.ts` (Node 22, stdlib only) validates the line (1-120 characters, single
line, not only whitespace) and writes it to
`(MAKEFUN_OUTPUT_DIR ?? "/output")/entry.txt`.
